# Manual Prático de Git e GitHub

Este é um manual colaborativo criado para ajudar iniciantes a aprenderem os conceitos e comandos básicos de Git e GitHub. O manual foi desenvolvido como parte de um projeto acadêmico e contém exemplos práticos, explicações detalhadas e recursos visuais para facilitar o aprendizado.

## Sobre o Projeto

Este manual foi criado com o objetivo de fornecer uma introdução prática e acessível ao Git e GitHub. Cada seção contém exemplos práticos, comandos explicados e recursos visuais para facilitar o entendimento dos conceitos.

## Como Usar Este Manual

1. Comece pela [Introdução](01-introducao.md) para entender os conceitos básicos
2. Siga a ordem dos módulos para um aprendizado estruturado
3. Pratique os comandos enquanto lê cada seção
4. Use as imagens e exemplos como referência visual

## Contribuição

Este é um projeto colaborativo. Se você encontrar algum erro ou tiver sugestões de melhoria, sinta-se à vontade para abrir uma issue ou enviar um pull request.
