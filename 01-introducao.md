# Introdução ao Git e Controle de Versão

## O que é Controle de Versão?

Controle de versão é um sistema que registra as mudanças feitas em um arquivo ou conjunto de arquivos ao longo do tempo, permitindo que você recupere versões específicas desses arquivos quando necessário. É como ter um "salvamento" do seu trabalho em diferentes momentos, permitindo que você volte a qualquer ponto anterior se necessário.

### Problemas Resolvidos pelo Git

Antes do Git e outros sistemas de controle de versão, os desenvolvedores enfrentavam vários desafios:

1. **Backup Manual**: Era necessário fazer cópias manuais dos arquivos para backup
2. **Colaboração Difícil**: Trabalhar em equipe era complicado sem um sistema centralizado
3. **Rastreamento de Mudanças**: Era difícil saber quem fez quais alterações e quando
4. **Conflitos de Código**: Resolver conflitos entre diferentes versões do mesmo arquivo era trabalhoso

O Git resolve esses problemas oferecendo:

- Rastreamento automático de mudanças
- Facilidade para trabalhar em equipe
- Capacidade de voltar a versões anteriores
- Sistema de branches para trabalhar em funcionalidades separadamente

## Breve Histórico do Git

O Git foi criado em 2005 por Linus Torvalds, o criador do Linux. A história do Git começou quando a relação entre a comunidade que desenvolvia o kernel do Linux e a empresa que mantinha o BitKeeper (sistema de controle de versão proprietário) se rompeu.

Torvalds criou o Git com os seguintes objetivos:

- Velocidade
- Design simples
- Suporte forte para desenvolvimento não-linear
- Totalmente distribuído
- Capaz de lidar com projetos grandes como o kernel do Linux

## Diferença entre Git e GitHub

É importante entender que Git e GitHub são coisas diferentes:

### Git
- Sistema de controle de versão
- Ferramenta que você instala localmente
- Gerencia o histórico do seu código
- Funciona offline
- Gratuito e open source

### GitHub
- Plataforma web que hospeda repositórios Git
- Oferece interface gráfica para Git
- Adiciona funcionalidades sociais e colaborativas
- Permite compartilhar código com outros desenvolvedores
- Oferece recursos adicionais como:
  - Pull Requests
  - Issues
  - Wikis
  - GitHub Pages
  - GitHub Actions

## Por que Usar Git?

1. **Controle de Versão**: Mantém um histórico completo de todas as mudanças
2. **Colaboração**: Facilita o trabalho em equipe
3. **Backup**: Seu código está sempre seguro
4. **Organização**: Mantém seu projeto organizado e estruturado
5. **Flexibilidade**: Permite trabalhar em diferentes funcionalidades simultaneamente

## Exemplo Prático

Imagine que você está escrevendo um documento importante. Com Git, você pode:

1. Salvar cada versão importante
2. Voltar a qualquer versão anterior
3. Criar diferentes versões do mesmo documento
4. Mesclar diferentes versões
5. Trabalhar em equipe sem sobrescrever o trabalho dos outros
