## Introdução ao Git e ao Controle de Versão

## O que é controle de versão
Controle de versão é um sistema que registra alterações feitas em arquivos ao longo do tempo, permitindo voltar a versões anteriores e trabalhar em equipe sem conflitos.

## Problemas resolvidos pelo Git
- Permite colaboração simultânea sem perder histórico
- Facilita a recuperação de versões anteriores
- Ajuda no gerenciamento de mudanças em projetos

## Breve histórico do Git
Criado por Linus Torvalds em 2005 para gerenciar o código-fonte do Linux.

## Diferença entre Git e GitHub
- Git: sistema de controle de versão local
- GitHub: plataforma online que hospeda repositórios Git, facilitando colaboração remota
